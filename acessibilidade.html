Acessibilidade do site do Folio

Versão de 22 de outubro de 2026. Esta declaração vale para o site de download (folio.pedronvitoriano.com e a cópia no GitHub Pages).

Meta

O site busca o nível AA das Diretrizes de Acessibilidade para Conteúdo Web (WCAG 2.2).

O que foi feito e conferido

  • Teclado: todos os links e botões são alcançados com Tab, na ordem da leitura, com contorno de foco visível.
  • Leitor de tela: um título principal, regiões nomeadas, imagens com descrição e a troca de sistema no painel de download anunciada. As capturas que só decoram a animação ficam escondidas do leitor, sem esconder controles.
  • Movimento: a troca automática das telas no topo tem botão Pausar, para quando o mouse ou o foco estão nela e não acontece quando o sistema pede menos movimento; nesse caso também saem o desfoque e a inclinação.
  • Contraste: todo texto tem pelo menos 4,5:1 sobre o fundo. Isso é conferido automaticamente a cada mudança.
  • Tela pequena e zoom: o site funciona a partir de 320 px de largura sem rolagem lateral, e o zoom não é bloqueado.
  • Sem JavaScript: o conteúdo e todos os downloads continuam disponíveis.

Limites conhecidos

  • O site ainda não foi testado com leitores de tela de verdade (NVDA, VoiceOver); as conferências são automáticas.
  • As capturas de tela mostram texto pequeno do app como imagem; o que importa delas está escrito ao lado.

Encontrou uma barreira?

Conte em https://github.com/pedronvitoriano/folio-releases/issues o que tentou fazer, a página e o navegador. Se preferir não escrever em público, use no Folio o menu ··· › Reportar um problema.
